# ✅ ユースケース: ユーザー登録（サインアップ）

## 📝 ユースケース概要

| 項目 | 内容 |
|-----|------|
| ユースケース名 | ユーザー登録（サインアップ） |
| 実行者（アクター） | ゲストユーザー（未登録ユーザー） |
| 目的・動機 | 自分のアカウントを作成し、ログイン状態でサービスを利用できるようにする |
| 入力 | `email`, `password`（UI経由で送信） |
| 出力 | JWTトークン（`accessToken`）、登録成功のメッセージ |
| 事前条件 | 有効なメールアドレスと安全なパスワード（8文字以上等） |
| 正常フロー | 入力検証 → パスワードハッシュ化 → DBに保存 → JWT生成 → トークン返却 |
| 例外フロー | メール形式不正 / パスワード弱い / 登録済みメール / DBエラー / JWT失敗 |
| 事後条件（結果） | ユーザーがアカウントを作成し、トークンを保持したログイン状態になる |

## ✨ シーケンス詳細

1. ユーザーが `email` と `password` を入力し「登録」ボタンを押す。
2. システムは入力値を検証する。
3. パスワードを `bcrypt` でハッシュ化。
4. `email` の重複がなければユーザー情報をDB（SQLite）に保存。
5. 登録された `userId`, `email` を元に `JWT` を生成。
6. トークンをクライアントに返却（通常は`accessToken`）。
7. ユーザーはトークンを保持し、次回から認証済みとして扱われる。

## 💡 設計詳細

### パスワードポリシー
- 最小8文字
- 大文字・小文字を含む
- 数字を含む
- 特殊文字を含むことを推奨

### エラーメッセージ一覧
```typescript
const ERROR_MESSAGES = {
  EMAIL_EXISTS: 'このメールアドレスは既に登録されています',
  INVALID_EMAIL: 'メールアドレスの形式が正しくありません',
  WEAK_PASSWORD: 'パスワードは8文字以上で、大文字・小文字・数字を含める必要があります',
  SERVER_ERROR: 'サーバーエラーが発生しました',
  JWT_ERROR: '認証トークンの生成に失敗しました'
};
```

### JWTペイロード構成
```typescript
interface JWTPayload {
  sub: string;      // userId
  email: string;    // メールアドレス
  iat: number;      // 発行時刻
  exp: number;      // 有効期限
}
```

### トークン設定
```typescript
const TOKEN_CONFIG = {
  accessToken: {
    expiresIn: '1h',
    algorithm: 'HS256'
  },
  refreshToken: {
    expiresIn: '30d'
  }
};
```
