# 新しい認証・認可機能の実装ステップ

## 1. 認証機能の基盤整備

### 1.1 認証サービスの作成
- `src/services/auth/`ディレクトリを作成
- `AuthService.js`を作成し、認証関連のロジックを集約
- 以下の機能を実装：
  - メールアドレス認証
  - Googleアカウント認証
  - パスワードリセット
  - メールアドレス確認

### 1.2 ユーザー状態管理の改善
- Vuexストアに認証状態管理を追加
- `src/store/modules/auth.js`を作成
- 以下の状態を管理：
  - ログイン状態
  - ユーザー情報
  - ローディング状態
  - エラー状態

## 2. 認可（権限）機能の実装

### 2.1 ロールベースアクセス制御（RBAC）の実装
- `src/services/auth/roles.js`を作成
- 以下のロールを定義：
  - 一般ユーザー（GENERAL_USER）
  - プレミアムユーザー（PREMIUM_USER）
  - 管理者（ADMIN）

### 2.2 ユーザーロールの管理
- Firestoreのユーザードキュメントにロールフィールドを追加
- ロール変更機能の実装
- ロールに基づくUI表示の制御

## 3. セキュリティ強化

### 3.1 Firebase Security Rulesの更新
- Firestoreのセキュリティルールを更新
- 以下のアクセス制御を実装：
  - ユーザー自身のデータのみ読み書き可能
  - 管理者は全データにアクセス可能
  - ロールに基づくコレクションアクセス制御

### 3.2 入力バリデーションの強化
- フロントエンド側でのバリデーション強化
- バックエンド（Firebase Functions）でのバリデーション追加

## 4. UI/UX改善

### 4.1 認証関連画面の改善
- ログイン画面のデザイン刷新
- パスワードリセット画面の追加
- メールアドレス確認画面の追加
- エラーメッセージの改善

### 4.2 ユーザー管理機能の追加
- プロフィール編集機能の拡張
- アカウント削除機能の追加
- パスワード変更機能の追加

## 5. テストとデプロイ

### 5.1 テストの実装
- 認証フローのユニットテスト
- ロールベースアクセスのテスト
- セキュリティルールのテスト

### 5.2 デプロイ準備
- 本番環境の設定確認
- 環境変数の設定
- デプロイスクリプトの更新

## 実装の優先順位

1. 認証機能の基盤整備（1.1, 1.2）
2. セキュリティ強化（3.1）
3. 認可機能の実装（2.1, 2.2）
4. UI/UX改善（4.1）
5. ユーザー管理機能の追加（4.2）
6. テストとデプロイ（5.1, 5.2）

## 注意点

1. 既存の認証機能を維持しながら、段階的に新機能を追加
2. セキュリティを最優先事項として考慮
3. ユーザー体験を損なわないよう、スムーズな移行を計画
4. 十分なテストカバレッジを確保
5. エラーハンドリングを適切に実装
